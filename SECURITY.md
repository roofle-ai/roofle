# Security policy

Roofle records and transcribes audio, so security and privacy reports matter.

## Reporting a vulnerability

Please **do not open a public issue**. Use GitHub's private reporting:
**Security → Report a vulnerability** on this repository.

Include what you found, how to reproduce it, and the affected version. I will acknowledge the report and keep you updated as it is fixed.

## Scope

Of particular interest: leaking audio, transcripts or API keys; unintended network access; and the update and signing path.

## Supported versions

Only the latest release is supported.
